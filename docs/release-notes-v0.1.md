# AI Dev Control v0.1 — リリースノート（案）

**状態: 未リリース。** 家主の承認、PR 作成、タグ作成はまだ行われていません。この文書は Phase 1F 時点（ベース `0824ec9` に Phase 1F の変更を加えたもの）の実装内容に基づきます。

## 対象範囲
複数プロジェクトの開発状況を、AI を担当者として管理する**個人利用のブラウザアプリ**。最終承認者は人間（家主）。データはブラウザの localStorage のみ。GitHub は公開リポジトリを読み取り専用（GET）で参照します。

## 実装済み機能
各項目の確認区分: **テスト済み**=自動テスト（Vitest/Playwright、GitHub 通信はモック）で確認、**家主確認**=家主が Netlify 実環境で確認と報告（Claude Code は未実行）。

## 既知の制約
- **同時刻の保存**: 2つのタブがほぼ同時に保存した場合の排他は保証できません（ブラウザが localStorage の排他を保証しないため）。家主の実環境確認もこのケースは対象外でした。
- **認証なし**: 公開 Function は誰でも呼び出せます（許可リストでリポジトリを制限）。共有の GitHub 未認証レート制限（60回/時間）を消費される可能性があります。
- **GitHub**: 最新30件のみ、1同期=4リクエスト、ETag/304 なし、ページングなし。実環境での異常系（レート制限枯渇、404 等）と `GITHUB_TOKEN` 設定時の動作は未検証。確認した実リポジトリは `pofuru-web/ai-dev-lab-public` のみ。
- **データの置き場所**: ブラウザ内のみ。別端末・別ブラウザへは自動で移りません（バックアップ→復元を使用）。localStorage の容量制限があります。
- **日付**: 期間集計はブラウザの時間帯基準。日付なしの記録は期間集計に入りません。日をまたぐ開始・終了の記録は開始日に計上します。
- **レビュー指摘の状況**（docs/review-v0.1.md）: M-1・M-2・M-3・M-5 は Phase 1E で修正済み（自動テスト済み、実環境は未確認）。**M-4（公開 Function の悪用余地）は Phase 1F で CDN キャッシュによる軽減策のみ実装**（Netlify 上は未検証。アクセス制限ではなく、悪意ある呼び出しによる利用枠の消費は完全には防げない。docs/function-protection-options.md、docs/netlify-cache-verification.md）。M-2 は「他タブの保存を上書きしない」確認を追加したが、検査と書き込みは原子的ではなく、同時刻の保存は引き続き保証できない。Low の一部（ErrorBoundary、CSP ヘッダー、モーダルの操作性、バックアップのサイズ上限、日付関連、控えの肥大など）は未修正で、既知の制約または改善候補。
- **破損データの控え**: 破損データを置き換える前に `adc:corrupt-copy:*` として自動保存するが、控えをダウンロードする画面は未実装（ブラウザの開発者ツールで取り出す）。
- **開発用依存の脆弱性**: `npm audit` moderate 7件（typescript-eslint 経由の minimatch。開発時のみ、本番依存は 0 件）。強制更新はしていません。
- **Netlify 環境**: Node は `.nvmrc`（22）で指定。Phase 1E の受入でデプロイ成功と Node 22 を家主が確認済み。
- **同期のキャッシュ**: 直前の同期から60秒以内は同じ結果が返り、「最終取得日時」が更新されないことがある。許可リストから外したリポジトリの旧キャッシュは最大60秒返り得る。キャッシュは認証・アクセス制限の代わりにならない。
- **利用枠・費用**: 家主のプラン・利用枠・超過時の動作・追加請求の有無は未確認（確認手順は docs/netlify-cache-verification.md）。
